# Skills Toolbox — Agent Rules

Edit files only inside this repository. Global skill installs (`~/.gemini/config/skills/`) are read-only; the user deploys manually.

Skills must use generalised placeholders — `main`, `staging`, `JIRA-` — never company names, branch prefixes like `ENG-`, or environment names like `prod3`.

When editing `README.md`: list skills in two groups — **General Skills** and **Meteor Skills** — sorted alphabetically by name within each group.
