# Repository Rules & Context

This repository (`skills`) contains a set of skills that we develop and publish.

## 🛑 Critical Agent Directives

When working in this repository, you must ALWAYS adhere to the following rules:

1. **ONLY MODIFY FILES IN THIS REPOSITORY**: All edits, additions, or deletions to skills must happen exclusively within this local repository.
2. **NEVER TOUCH GLOBALLY INSTALLED SKILLS**: Do not attempt to modify, overwrite, or update user skills installed in the system or other projects (e.g., files under `~/.gemini/config/skills/` or similar configuration directories). 
3. **NO INSTALLATION REQUIRED**: Your job is only to write and update the source code of the skills in this repository. The user will manually install the skills into their system configuration afterwards.
